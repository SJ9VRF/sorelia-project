# Artifact ledger

This directory contains retained engineering evidence from selected release iterations. Historical artifacts are kept only where they support methodological corrections, null/adverse results, browser execution, or claim/evidence provenance.

Do not interpret historical smoke metrics as a leaderboard. The authoritative evidence boundary is `docs/TRUTH_AUDIT.md`, `docs/EVIDENCE_TIERS.md`, and `docs/EXPERIMENT_REGISTRY.md`.

Current public-release verification is summarized in `V140_RELEASE_REPORT.json`.
