# Git history boundary

**Author:** Aura Yavary

Retained Git history begins with the imported v1.5.0 release candidate. Earlier development history was not present in the source archive and has **not** been reconstructed.

From that boundary forward, the repository contains real incremental commits, including the Evidence Layer and v1.7 Traceability Layer. Historical pre-v1.5 method corrections are supported by archived artifacts, release notes, and decision logs—not invented commit hashes.

A portable bundle is shipped at `artifacts/git_history/sorelia-v1.7.0.bundle`.

```bash
git clone artifacts/git_history/sorelia-v1.7.0.bundle sorelia-with-history
```
