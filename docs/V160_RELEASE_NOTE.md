# SORELIA v1.6.0 — Evidence Layer

v1.6.0 adds a research-process layer beneath the polished flagship presentation. The release includes nine journaled experiment families, six documented failed/invalidated assumptions, eight structured research decisions, unexpected findings, real evaluation tables, curated raw trajectories/eval/config/ablation artifacts, qualitative cases, evidence plots, and a portable real Git history beginning from the available v1.5.0 baseline archive.

No historical commits were backdated. No failed experiment or metric was invented. Earlier development history is represented by retained artifacts, manifests, changelog records and result notes.
