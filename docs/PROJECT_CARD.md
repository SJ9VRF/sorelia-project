# Portfolio project card

**SORELIA — Tracking and Training the Moving Failure Frontier of Interactive Agents**  
**Aura Yavary**

Post-training can improve aggregate success while moving reliability risk into new failure mechanisms. SORELIA tracks which failures disappear, persist, expand, emerge, split, or merge across policy updates, then uses those transitions to allocate the next fixed verified-data budget.
