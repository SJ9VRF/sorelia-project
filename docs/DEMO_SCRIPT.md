# Demo script

## 90-second version

1. Run the same task suite with policy v0 and show trajectory/failure traces.
2. Open the failure-frontier view: discovered mechanisms, stable IDs and risk mass.
3. Train once and re-evaluate.
4. Highlight one contracting/extinct mechanism and one emergent/expanding mechanism.
5. Show the risk-displacement ratio: the update can improve task success yet still move risk elsewhere.
6. Show how SORELIA changes the next training allocation while a static failure-frequency baseline does not.
7. End on a held-out task or environment family, not a generated training example.

## What not to demo

Do not lead with dashboards, synthetic percentages or module count. Lead with one concrete failure that changes identity/risk across versions, then reveal the system that tracks it.
