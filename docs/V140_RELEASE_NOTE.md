# SORELIA v1.4.0 release note

v1.4.0 hardens SORELIA as a public research repository without changing the evidence tier of the scientific claims.

## Added

- `CONTRIBUTING.md` with evidence-first PR requirements.
- `SECURITY.md` with sandbox, credential, and high-risk-action boundaries.
- `CODE_OF_CONDUCT.md` centered on rigorous, respectful, non-inflated research practice.
- `docs/BENCHMARK_CARD.md` and `docs/SYSTEM_CARD.md`.
- `docs/EXPERIMENT_REGISTRY.md` separating executed evidence from pending paper-scale work.
- `docs/DECISION_LOG.md` documenting major scientific choices and rejected shortcuts.
- `docs/REVIEWER_REPRODUCTION.md` with static, fast, and full reproduction paths.
- `scripts/reviewer_demo.sh` for a one-command reviewer integrity path.
- GitHub issue and pull-request templates that require hypothesis, controls, falsification conditions, and contamination notes.
- public-repository contract tests.

## Integrity

The release continues to retain null/adverse results and does not claim frontier-model superiority, production reliability, completed human calibration, or SOTA performance.
